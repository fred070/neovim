# Resource Usage vs. Total Capacity in Kubernetes

This document outlines how to monitor and alert on CPU, memory, and storage utilization against total allocatable resources at different scopes: Cluster, Node, and Tenant (via Capsule).

## 📊 Usage vs. Capacity Metrics

| Scope    | Resource     | Metric (Usage)                                     | Metric (Total)                                      | Description                                                                 | Threshold | Severity | Alert Condition                        | User Impact                                            |
|----------|--------------|----------------------------------------------------|-----------------------------------------------------|-----------------------------------------------------------------------------|-----------|----------|----------------------------------------|---------------------------------------------------------|
| Cluster  | CPU          | `sum(container_cpu_usage_seconds_total)`           | `sum(kube_node_status_allocatable_cpu_cores)`       | Total CPU used across all containers vs. total allocatable cluster CPU      | >90%      | Critical | Sustained 90% usage for 2 intervals    | Cluster-wide CPU pressure, pod throttling               |
| Cluster  | Memory       | `sum(container_memory_usage_bytes)`                | `sum(kube_node_status_allocatable_memory_bytes)`    | Memory used across all containers vs. total cluster allocatable memory      | >85%      | Critical | Sustained 85% usage                    | Cluster OOM risk, eviction, degraded service            |
| Cluster  | Ephemeral    | `sum(container_fs_usage_bytes)`                    | `sum(kube_node_status_allocatable_ephemeral_bytes)` | Disk used by all containers vs. total ephemeral storage capacity            | >80%      | Warning  | Sustained high usage                   | Storage pressure, pod eviction                         |
| Node     | CPU          | `container_cpu_usage_seconds_total` per node       | `kube_node_status_allocatable_cpu_cores`            | CPU usage vs. allocatable CPU per node                                     | >90%      | Critical | Sustained node CPU usage               | Throttling, scheduling delays                          |
| Node     | Memory       | `container_memory_usage_bytes` per node            | `kube_node_status_allocatable_memory_bytes`         | Memory usage vs. allocatable memory per node                               | >85%      | Critical | OOM risk on node                       | Pod eviction                                           |
| Node     | Ephemeral    | `container_fs_usage_bytes` per node                | `kube_node_status_allocatable_ephemeral_bytes`      | Ephemeral storage usage vs. allocatable on node                            | >80%      | Warning  | Disk pressure                         | Write failures, eviction                              |
| Tenant   | CPU          | `capsule_tenant_cpu_usage_cores`                   | `capsule_tenant_cpu_quota_cores`                    | CPU usage vs. quota per tenant namespace                                   | >90%      | Critical | Tenant CPU quota breach                | App throttling, scheduling blocked                    |
| Tenant   | Memory       | `capsule_tenant_memory_usage_bytes`                | `capsule_tenant_memory_quota_bytes`                 | Memory usage vs. quota per tenant                                          | >85%      | Critical | Quota breach, eviction risk            | OOMs, degraded experience                             |
| Tenant   | Ephemeral    | `capsule_tenant_ephemeral_storage_usage_bytes`     | `capsule_tenant_ephemeral_storage_quota_bytes`      | Ephemeral usage vs. tenant quota                                           | >80%      | Warning  | Sustained high usage                   | Risk of pod failures                                  |
| Tenant   | PVC          | `capsule_tenant_pvc_storage_usage_bytes`           | `capsule_tenant_pvc_storage_quota_bytes`            | PVC usage vs. PVC quota                                                    | >90%      | Warning  | High usage                             | New PVCs blocked, storage saturation                  |

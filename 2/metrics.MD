# 📊 Resource Usage Metrics (CPU, Memory, Disk, Network)

| Layer      | Category       | Metric                                               | Description                                           | Threshold                     | Severity | Alert Condition                            | User Impact                                                   |
|------------|----------------|-------------------------------------------------------|-------------------------------------------------------|-------------------------------|----------|--------------------------------------------|----------------------------------------------------------------|
| Cluster    | CPU Usage      | `sum(container_cpu_usage_seconds_total)`             | Aggregated CPU usage across all workloads             | >80% of total cluster CPU     | Critical | Sustained for 2 consecutive intervals       | Overall cluster performance degradation                       |
| Cluster    | Memory Usage   | `sum(node_memory_MemAvailable_bytes)`                | Total available memory across all nodes               | <15% of total memory          | Warning  | Less than 15% free for 5 mins               | Risk of OOM kills and degraded workloads                      |
| Cluster    | Disk Usage     | `sum(node_filesystem_usage_bytes)`                   | Total disk usage across nodes                         | >85%                          | Warning  | Exceeds 85% usage for 5 mins                | Storage pressure leading to pod eviction                     |
| Cluster    | Network Usage  | `cluster_network_receive_bytes_total`                | Cluster-wide ingress traffic rate                     | 2x baseline                   | Info     | Sudden change over 5 min                    | Indicates abnormal inbound traffic                           |
| Node       | CPU Usage      | `node_cpu_utilization`                               | CPU usage per node                                    | >85%                          | Critical | Sustained 3 intervals                       | Node scheduling delays or throttled pods                      |
| Node       | Memory Usage   | `node_memory_Active_bytes`                           | Active memory used by the node                        | >90%                          | Critical | Exceeds threshold 3 times in 10 mins        | Pods may get evicted or OOM killed                           |
| Node       | Disk Usage     | `node_filesystem_avail_bytes`                        | Free disk space on node volume                        | <10%                          | Critical | Below 10% for 5 mins                         | Kubelet may mark node as NotReady                            |
| Node       | Network Usage  | `node_network_transmit_errs_total`                   | Packet transmission errors on a node                  | >0                           | Warning  | Non-zero value in 5 min window              | Packet drops, degraded connectivity                          |
| Tenant     | CPU Usage      | `capsule_tenant_cpu_usage` *(custom)*                | CPU usage aggregated by tenant                        | >90% of quota                 | Warning  | Sustained 5m usage above 90%                | Tenant at risk of CPU quota throttling                       |
| Tenant     | Memory Usage   | `capsule_tenant_memory_usage` *(custom)*             | Memory usage aggregated by tenant                     | >80% of quota                 | Warning  | Sustained 5m usage above 80%                | Memory pressure inside tenant workloads                      |
| Tenant     | CPU Usage      | `capsule_tenant_pods_running` *(custom)*             | Number of pods running per tenant                     | >allocated quota              | Critical | Exceeds quota for 2+ intervals              | Scheduling failure or policy violation                       |
| Tenant     | Network Usage  | `capsule_tenant_network_bytes_total` *(custom)*      | Aggregated network usage by tenant                   | >90% of quota                 | Warning  | Breach sustained over 5 minutes             | Tenant may hit rate limits or quotas                         |
| Pod        | CPU Usage      | `container_cpu_usage_seconds_total{pod=...}`         | CPU usage by pod                                      | >80% of CPU request           | Warning  | Sustained usage for 5 mins                  | Throttling or degraded performance in pod                    |
| Pod        | Memory Usage   | `container_memory_usage_bytes{pod=...}`              | Memory usage by pod                                   | >90% of request               | Critical | Immediate alert on breach                   | Pod may get killed due to OOM                                |
| Pod        | Stability      | `kube_pod_container_status_restarts_total`           | Container restarts within pod                         | >3 restarts in 5m             | Warning  | More than 3 restarts within window          | Unstable or crashing application                             |
| Pod        | Network Usage  | `container_network_receive_bytes_total{pod=...}`     | Inbound traffic to pod                                | 2x baseline                   | Warning  | Spike sustained for 3 intervals             | Possible DDoS or app overload                                |
| Container  | CPU Usage      | `container_cpu_usage_seconds_total{container=...}`   | CPU usage by container                                | >90% of request               | Critical | Sustained usage for 5 mins                  | Throttling of container workloads                            |
| Container  | Memory Usage   | `container_memory_working_set_bytes{container=...}`  | Working set memory in container                       | >95% of memory limit          | Critical | Alert immediately on threshold              | High risk of OOM, possible kill                              |
| Container  | Disk Usage     | `container_fs_usage_bytes`                           | Filesystem usage by container                         | >80% of allocated volume      | Warning  | Exceeds threshold for 5 mins                | Disk space issues, write errors or pod eviction              |
| Container  | Network Usage  | `container_network_transmit_packets_dropped_total`   | Dropped packets during egress                         | >0                           | Critical | Any drop detected                            | Communication reliability issues                             |
